## Сущности

 - **Player**. Является сущностью, содержащей в себе все неигровые данные игрока, типа паролей, почты, даты регистрации и всякого такого. Вернее, всё это появится когда-нибудь в будущем, сейчас есть только имя и методы работы с ним (остальное не стал реализовывать ибо там логика абсолютно идентичная)
 - **Spaceship**. По сути, *персонаж* игрока в игровом мире. Вот его репозиторий, в компенсацию к предыдущему, содержит целую кучу методов, типа поиска по критериям, создания, удаления, очищения старых и тд.
 - **Galaxy**. Игровой мир. По сути, коллекция звёзд с версией. Существует в единственном экземпляре, неизменяемая, можно только перезаписать, создав новую и удалив старую и почистив всю базу вместе с ней.
 - **Star**. На уровне бизнес логики - часть Galaxy. На уровне бд - отдельная сущность, поэтому выношу
 - **SpaceshipStarVisit**. Сущность, реализующая связь m-to-m между звездами и кораблями, но хранящая еще дополнительную информацию о дате создания связи, поэтому вынесена отдельно

## Связи
- o-to-o: **Player + Spaceship**: у каждого игрока только один корабль, и наоборот, у корабля один владелец. У них буквально даже первичный ключ общий, настолько они близки.
- o-to-m: **Galaxy + Star**: ну понятно, галактика содержит в себе множество звёзд, а каждая звезда принадлежит только одной галактике
- m-to-m: **Star + Spaceship (через SpaceshipStarVisit)**: корабль может посетить много планет, и одну планету могут посетить много кораблей
