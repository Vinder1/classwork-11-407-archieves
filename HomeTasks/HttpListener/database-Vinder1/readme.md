**Транзакция:**

Используется при создании подарка. В процессе друг за другом выполняются три действия - списание монет, начисление монет другому и создание подарка. Очевидно, что если что-то из этой цепочки не будет выполнено, то кто-то останется в несправедливом минусе, поэтому надо будет осторожно отменять остальные действия. Собственно, для этого и применяется транзакция.

  

**Функции и процедуры:**
