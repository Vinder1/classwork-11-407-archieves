[Emerald] - Я решил дать красивое имя своему микро фреймворку, чтобы было приятнее и веселее с ним работать

[Доступ по ролям] - Некоторые страницы не требуют от пользователя ничего (в частности, главная страница). Некоторые требуют наличия токена и, соответственно, прав зарегистрированного пользователя, иначе будут выкидывать на страницу авторизации. А есть страница /admin (расположенная в контроллере AdminController), которая требует особую роль 'admin'. Получить её можно только вручную поменяв значение роли в бд, настолько она привилегированная. На ней нет никакой панели управления, она просто смешная, но свою роль эксклюзивности она выполняет. 

[Авторизация] - На основе JWT + Refresh токена. В моей реализации RT - это такой же токен, но лежащий в защищенных куки. Как работает. При попытке войти на страницу, где требуется авторизация, js запрашивает данные пользователя, предоставляя jwt. Если jwt просроченный или его нет, сервер сигнализирует об этом, и тогда js запрашивает новый jwt, автоматически предоставляя rt. Если rt рабочий, то сервер возвращает новый токен, и js с новым токеном пытается сделать всё сначала, опять запрашивая данные пользователя. Если rt тоже не рабочий, то js выкидывает пользователя на страницу авторизации. Rt автоматически генерируется и сохраняется куда надо при регистрации и авторизации.
